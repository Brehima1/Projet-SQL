🔍 Projet SQL – Murder Party à l’Hôtel
Analyse complète des invités, activités, paiements et niveaux de suspicion

Bienvenue dans ce projet entièrement réalisé en SQL, conçu pour analyser les données d’un hôtel fictif dans un univers de murder party.
L’objectif : exploiter différentes tables (guests, rooms, transactions, employees, activity_log, suspicions…) pour résoudre une enquête en manipulant, croisant et interprétant des données.

Ce projet constitue un excellent exercice de requêtes SQL avancées, incluant :
✔️ agrégations
✔️ jointures
✔️ conditions complexes
✔️ mises à jour
✔️ sous-requêtes
✔️ analyse d’activité temporelle

🎯 Objectifs du projet

Explorer la base de données de l’hôtel

Retrouver les déplacements et actions des invités

Analyser paiements et transactions

Identifier les suspects clés grâce à leur niveau de suspicion

Manipuler les données pour résoudre l’enquête

Chaque question correspond à une requête SQL précise permettant de reconstituer les événements de la soirée.

🗂️ Contenu couvert
🌐 1. Gestion des invités

Lister tous les invités

Filtrer par date de départ

Rechercher par initiale

Associer chaque invité à sa chambre

🍽️ 2. Analyse des activités

Qui était au restaurant à une heure précise ?

Qui s’y est disputé ?

Qui se trouvait dans la cuisine à 21h ?

🧮 3. Analyse financière

Revenu total

Paiements supérieurs à la moyenne

Paiements par étage

Plus gros paiement effectué

🕵️ 4. Enquête & Suspicion

Mise à jour automatique des niveaux de suspicion

Total par type de suspect

Identification du suspect numéro 1

👔 5. Ressources humaines

Salaire moyen par shift

📌 Ce que vous apprendrez

Construire et structurer un fichier SQL professionnel

Rédiger des requêtes lisibles, commentées et efficaces

Utiliser des jointures (INNER JOIN) dans un contexte réaliste

Travailler avec des dates, heures et filtres temporels

Manipuler des valeurs numériques (moyenne, somme, maximum…)

Mettre à jour des données existantes (UPDATE)

Concevoir une analyse complète orientée enquête

🚀 Comment utiliser le projet ?

Importer la base de données fournie (ou créer vos tables selon le schéma indiqué).

Copier-coller le fichier SQL dans votre SGBD (MySQL, PostgreSQL, SQLite, etc.).

Exécuter les requêtes une par une pour reconstituer le scénario.

Tenter de déterminer qui est le principal suspect grâce aux données.
